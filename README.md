# The Cammino Diary — camino data

The data package of The Cammino Diary, an app for pilgrims on the Camino de Santiago.
This repository holds **data only**: the app downloads it from the release
[`camino-data`](https://github.com/LPPL1316/cammino-data/releases/tag/camino-data),
checks every file against its sha256 and keeps the data bundled with the app as the
fallback.

## What is in the release

- `manifest.json`: for each camino, the date of its data, the data format and the size
  and sha256 of every file.
- `<camino>.track.geojson`, `.places.json`, `.stages.json`, `.pois.geojson`,
  `.elevation.json`: the route, places, classic stages, albergues and services, and the
  elevation profile.
- `<camino>.ATTRIBUTION.md`: the sources and licences of that camino's data.

Caminos: Camino Francés (`frances`), Fisterra–Muxía (`fisterra-muxia`), Camino Portugués
from Porto (`portugues`), Camino Portugués de la Costa (`portugues-costa`), Camino del
Norte (`norte`).

The files are generated by scripts from OpenStreetMap and the Copernicus DEM, never
copied from other apps, guidebooks or websites. Do not edit them by hand.
